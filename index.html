HOW TO PLAY

목적지는 같아도,
행운은 제각각.

01 / 인원과 이름을 정하세요

2~12명, 20·35·50초 중 선택한 뒤 출발 버튼을 누르세요. 이름은 최대 12글자이며, 입력하지 않으면 기본 이름을 사용해요. 모든 참가자는 같은 출발선·거리·운행 조건을 갖습니다.

02 / 운에 맡기고 응원하세요

자동차 공장 → 내륙 트럭 → 수출항 선적 → 자동차선 해상운송 → 현지항 하역 → 내륙 트럭 → 목적지 순서로 달립니다. 운전 조작은 없고, 랜덤 가속·대기 이벤트가 순위를 바꿔요.

03 / 실제 결승선 통과 순서가 최종 순위

도착 기록은 결승선 통과 시점으로 계산합니다. 초기 레인, 이름, 캐릭터에 따른 유불리는 없어요. 매번 새 난수로 운행을 생성하며, 독립 무작위 모드에서는 이전 결과가 우연히 반복될 수 있어요.

전체 순위 반복 방지 옵션

켜면 현재 인원수의 직전 완주 경기와 전체 순위가 같은 경주는 재추첨합니다. 2명에서는 결과가 번갈아 나옵니다. 매번 독립적인 무작위 결과를 원할 때는 이 옵션을 꺼 주세요.

잠깐 멈추거나 다시 달리고 싶을 때

일시정지 버튼 또는 Space 키를 누르세요. 다른 탭으로 이동하면 자동으로 멈춥니다. 상단 스피커로 효과음을 켤 수 있고, 기록은 이 브라우저에만 보관됩니다. iPhone·iPad의 파일 미리보기는 게임을 실행하지 못할 수 있어요. JavaScript를 지원하는 브라우저나 HTML 실행 앱에서 여세요.
